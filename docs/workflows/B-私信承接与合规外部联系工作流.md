# B 部分：私信承接与合规外部联系工作流

## 1. 目标

当用户主动表示想进一步咨询时，在平台规则允许的范围内完成：

`识别需求 -> 明确用户意愿 -> 解释服务范围 -> 提供合规联系入口 -> 记录上下文 -> 交给 C 部分`

本部分只处理“从直播间或平台私信到下一步联系”的承接，不处理添加微信后的长期运营。

## 2. 合规边界

不能把分行、同音字、emoji、谐音、图片藏字或故意拆分联系方式写成规避平台审核的操作方法。平台明确限制外部联系方式时，应遵守平台规则，避免批量发送、诱导跳转、隐藏联系方式或绕过审核。

可采用的方向：

- 优先使用平台允许的私信、预约、表单、客服或官方组件；
- 让用户明确表达需求，不主动向无关用户群发联系方式；
- 使用平台批准的企业号、客服工具或官方外部联系组件；
- 如平台允许用户主动选择外部联系方式，再向用户说明正式入口；
- 发送清晰、真实、可核验的身份和服务说明，不使用误导性话术；
- 保存用户授权、来源、咨询主题和承接时间。

## 3. 触发条件

只有出现以下情况之一，才进入 B 部分：

- 用户主动说想咨询、想看具体方案或想进一步沟通；
- 用户主动询问联系方式；
- 用户提交了明确的个案问题，公开回复无法完整处理；
- 用户同意接受后续服务说明。

不能因为用户只点赞、关注或发一个泛关键词，就默认其同意被导流或接受营销信息。

## 4. 标准流程

### B1. 识别用户需求

先判断用户属于哪一类：

- 需要公开内容解释；
- 需要补充材料后判断；
- 需要一对一咨询；
- 只是询问价格、时间或服务方式；
- 暂时没有明确需求。

不要第一句话就发送联系方式。先确认对方需要解决的问题和期望结果。

### B2. 说明承接方式

建议使用清晰表达：

> 你的情况需要结合具体背景判断。你可以先把问题和基本情况发在平台允许的私信里；如果你希望继续沟通，我再按照平台允许的方式告诉你下一步入口。

如果平台允许官方外部联系方式，可以说明：

> 这是我们的官方咨询入口，添加前请确认你愿意接受后续沟通。我们只会围绕你主动提出的问题联系，不会频繁打扰。

如果平台不允许外部导流，则停留在平台内，使用平台私信、预约、客服或官方表单完成承接。

### B3. 收集最小必要信息

只收集完成下一步所需要的信息：

- 平台昵称；
- 用户主动描述的问题；
- 问题发生的大致时间；
- 用户希望获得的帮助；
- 是否同意继续联系；
- 来源直播和时间。

不要在未说明用途的情况下索要身份证、银行卡、通讯录、完整聊天记录或其他敏感信息。

### B4. 发送承接信息

发送内容应包含：

- 我是谁；
- 能提供什么帮助；
- 下一步在哪里进行；
- 用户需要准备什么材料；
- 是否收费、如何收费，若暂未确定要明确说明；
- 用户可以随时停止沟通。

避免使用“保证挽回”“百分百有效”“马上解决”“不加就错过”等夸大或施压表达。

### B5. 交接给 C 部分

当用户完成合规外部联系或进入指定承接渠道后，建立一条交接记录：

```text
用户标识：
来源主播/场次：
进入时间：
用户原始诉求：
已发送的说明：
用户是否明确同意后续联系：
需要补充的信息：
下一步负责人：
```

## 5. B 部分话术结构

不固定使用一套“绕审核”的句子，而使用可审计的四段式：

```text
确认需求：我看到你想具体了解……
说明边界：直播间只能讲共性，不能替你直接判断……
提供选择：你可以继续在平台私信，或使用平台允许的官方入口……
确认意愿：你愿意继续沟通的话，回复“确认”即可；不需要也没关系。
```

## 6. 风险控制

- 不批量复制发送相同导流文案；
- 不使用隐写、谐音、拆字或图片藏字绕过审核；
- 不诱导用户提供隐私或敏感资料；
- 不把免费公开内容伪装成必须付费的服务；
- 不以情绪恐吓、虚假名额或虚假成功案例逼迫用户；
- 用户拒绝后停止追问；
- 定期检查平台规则和账号处罚提示。

## 7. B 部分验收标准

- 用户是主动或明确同意进入承接流程；
- 每个用户都有来源和诉求记录；
- 承接方式符合平台规则；
- 用户知道下一步、服务范围和可能费用；
- 没有使用隐蔽导流或规避审核手段；
- 交接记录完整，能够进入 C 部分。

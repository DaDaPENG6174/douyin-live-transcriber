# A 部分：直播间可复用话术表

> 本表根据当前五场直播录音提炼。它整理的是“话术结构”和“使用目的”，不是逐字照搬主播原话。实际使用时，应替换成自己的主题、案例和真实信息。

## 1. 直播间整体结构

```text
开场抓痛点
  -> 让用户识别自己
  -> 解释问题的底层原因
  -> 通过公屏互动筛选用户
  -> 给出一套可执行的方法
  -> 用案例验证方法
  -> 总结并安排下一段内容
  -> 关注、复访或平台内允许的下一步动作
```

## 2. 话术模块总表

| 编号 | 模块 | 目标 | 适用时机 |
|---|---|---|---|
| A-01 | 开场定位 | 让用户知道这场解决什么问题 | 开播前 1-3 分钟 |
| A-02 | 痛点识别 | 让用户产生“说的就是我”的感觉 | 开场后 |
| A-03 | 人群筛选 | 识别用户类型和问题状态 | 主题展开前 |
| A-04 | 共性解释 | 建立主播的分析框架 | 直播主体 |
| A-05 | 关键词互动 | 提高参与感和停留 | 每个小主题结束 |
| A-06 | 观点反转 | 打破用户原有认知 | 内容转折处 |
| A-07 | 故事背书 | 增强可信度和情绪连接 | 解释方法之后 |
| A-08 | 方法输出 | 给用户明确的下一步 | 每个内容段结尾 |
| A-09 | 案例拆解 | 把抽象观点变成具体场景 | 中段或问答段 |
| A-10 | 互动节点 | 维持直播间活跃 | 低互动或换主题时 |
| A-11 | 内容复盘 | 帮用户记住核心逻辑 | 主题结束时 |
| A-12 | 收尾复访 | 让用户关注并回到下一场 | 直播结束前 |

## 3. A-01 开场定位

### 目标

用一句话说明“今天讲谁、解决什么问题、听完能得到什么”。

### 话术模板

> 今天我们不讲空泛的道理，专门讲清楚【目标人群】遇到【具体问题】时，应该怎么判断、怎么处理。

> 如果你最近正在经历【现象 1】、【现象 2】或者【现象 3】，今天这场可以完整听一下。我们先讲共性规律，再讲具体处理方法。

> 今天的内容分三步：先判断问题是什么，再解释为什么会这样，最后讲你可以做什么。

### 使用要点

- 开场先讲用户问题，不先讲主播经历；
- 不承诺“百分百解决”；
- 主题不要太宽，最好围绕一个核心问题展开。

## 4. A-02 痛点识别

### 关系/婚姻类

> 你以为自己是在等对方回复，其实你可能一直在等待一个确定感。

> 很多关系的问题，不是某一句话造成的，而是双方长期的沟通方式已经形成了固定循环。

> 如果你总是在追问、解释、确认，对方却越来越沉默，先不要急着判断谁对谁错，我们先看这个循环是怎么形成的。

### 内容/人生类

> 很多人不是没有努力，而是一直在不适合自己的方向上用力。

> 有些事情不是你再坚持一点就能改变，先看清边界，才能决定下一步怎么走。

### 商品类

> 很多人不是不想改善，而是不知道应该看什么、怎么选、怎样判断是否适合自己。

> 先把需求和适用范围讲清楚，再决定要不要尝试，不要因为一句宣传就盲目下单。

## 5. A-03 人群筛选

### 数字选择

> 如果你是主动减少联系的一方，公屏打 1；如果是对方突然不回复，打 2；如果你们现在还在反复沟通，打 3。

### 关键词

> 如果你也在反复寻找确定感，把“确定”打在公屏上。

> 如果你现在最需要的是判断，不是安慰，把“判断”打出来。

> 如果你听到这里发现自己一直在消耗，可以把“停下来”打在公屏上。

### 使用目的

- 让观众公开确认自己的状态；
- 帮主播判断接下来重点讲哪类人；
- 把被动观看变成主动参与；
- 为后续案例拆解收集题材。

## 6. A-04 共性解释

### 关系类解释结构

```text
表面现象 -> 可能原因 -> 常见误判 -> 正确观察方式
```

### 示例

> 对方不回复，这是表面现象。真正要看的，是他是暂时需要空间，还是已经在关系里持续抽离。判断时要结合关系基础、冲突原因、联系变化和后续行动，不能只看一条消息。

### 婚姻类解释结构

```text
情绪抱怨 -> 关系中的真实利益 -> 可调整行为 -> 长期结果
```

### 示例

> 婚姻里的很多矛盾，表面上是某句话不好听，背后可能是信任、责任和价值感失衡。先把问题分清楚，再决定是沟通、调整边界，还是重新评估这段关系。

### 人生类解释结构

```text
当前困境 -> 能改变的部分 -> 不能改变的部分 -> 个人行动
```

### 示例

> 先把能改变和不能改变的事情分开。不能改变的部分，继续纠缠只会消耗；能改变的部分，才是你接下来真正要安排的行动。

## 7. A-05 公屏互动

### 低门槛互动

> 听懂的打“懂了”，有类似经历的打“有”，还没想明白的打“想听”。

> 你们更想先听原因，还是先听怎么做？原因打 1，方法打 2。

### 主题解锁式互动

> 这一段讲完，我们接下来进入具体方法。想听的朋友把赞点起来，给我一个继续讲下去的信号。

### 注意

互动是为了确认用户是否需要内容，不应承诺虚假的结果，也不应把点赞包装成必然的情感、财富或健康结果。

## 8. A-06 观点反转

五场录音中常见的有效结构是：先承认用户直觉，再指出直觉可能不完整。

### 模板

> 你以为【用户原判断】，但真正需要看的是【更底层因素】。

> 很多人第一反应是【常见做法】，但这个做法有一个问题：它可能会【风险】。

> 这不是让你什么都不做，而是先不要用【错误动作】替代【真正要解决的问题】。

### 示例

> 你以为减少联系就能让对方主动，但减少联系本身不是方法，关键是你们原来的沟通循环有没有改变。

## 9. A-07 故事背书

### 结构

```text
过去遇到的问题 -> 当时的错误理解 -> 后来发现的规律 -> 现在给用户的建议
```

### 模板

> 我以前也以为【旧观点】，后来经历了【具体情况】才发现，真正影响结果的是【规律】。所以今天我希望你们先看【关键判断】，不要只看表面现象。

### 使用要点

- 只讲真实经历；
- 不用虚构客户案例；
- 不泄露他人隐私；
- 故事最后必须回到用户能使用的方法。

## 10. A-08 方法输出

### 三步法

> 第一步，先判断【事实】；第二步，停止【无效动作】；第三步，尝试【可执行动作】。

### 关系类

> 先看对方有没有持续行动，再看他说了什么；先稳定自己的状态，再决定是否沟通；沟通时只解决一个问题，不要把所有旧账一次性翻出来。

### 婚姻类

> 先区分情绪问题、沟通问题和价值问题。情绪问题先降温，沟通问题讲具体事件，价值问题再评估双方是否愿意共同承担。

### 内容/人生类

> 先接受暂时不能改变的部分，再找自己能控制的一件小事。不要同时解决十个问题，先让一个动作真正发生。

### 商品类

> 先讲适用人群，再讲成分和使用方法，最后说明价格、售后和不适合的情况。用户了解完整信息后再决定是否购买。

## 11. A-09 案例拆解

### 公开案例结构

```text
用户问题 -> 已知事实 -> 不能确定的部分 -> 判断依据 -> 可执行建议
```

### 话术模板

> 这个案例先不要急着判断对方爱不爱。我们现在知道的是【事实】，还不知道的是【缺失信息】。所以目前只能得出【阶段性判断】，下一步可以先做【动作】。

### 复杂个案边界

> 公屏里我只能讲共性逻辑，不能只凭一句话替你下结论。你可以先把今天的方法听完，再通过平台允许的方式说明自己的情况。

## 12. A-10 直播间转化动作表

| 动作 | 使用目的 | 推荐表达 |
|---|---|---|
| 关注 | 让用户下次找得到直播 | “后面还会继续讲这个主题，想听后续的可以先关注。” |
| 点赞 | 确认用户是否愿意继续听 | “想继续听方法的，给我一个赞，我看一下大家的需求。” |
| 关键词 | 识别用户状态 | “符合这种情况的，把关键词打出来，我按人数多的部分先讲。” |
| 公屏选择 | 快速分类 | “想听原因打 1，想听方法打 2。” |
| 问答 | 收集共性问题 | “先把问题写清楚，我挑共性问题统一讲。” |
| 下一场预告 | 形成复访 | “今天先讲到这里，下一场继续拆解后面的部分。” |

## 13. A-11 内容段落复盘

每讲完一个主题，用三句话收束：

> 今天这一段最重要的不是【表面现象】，而是【底层判断】。

> 你接下来先不要做【无效动作】，先完成【一个具体动作】。

> 如果你还想继续听，下一段我们讲【下一主题】。

## 14. A-12 直播收尾

### 标准收尾

> 今天我们先把【主题】的底层逻辑讲清楚了：第一是【要点一】，第二是【要点二】，第三是【要点三】。大家先按照自己的情况做判断，不要急着照搬别人的答案。

> 后面还会继续讲【下一主题】。想听后续内容的可以先关注，下一场我们接着拆解。

### 复盘型收尾

> 如果你今天只记住三句话：第一，【总结一】；第二，【总结二】；第三，【总结三】。复杂情况不要在一句话里做决定，先把事实和目标分清楚。

### 风险边界

- 不使用“错过就永远没有机会”等虚假恐吓；
- 不承诺对方一定回头、一定成交或一定改变；
- 不把点赞、关注、灯牌与不可验证的结果绑定；
- 不公开展示用户隐私和聊天记录。

## 16. A 部分使用顺序

实际准备一场直播时，先填写：

```text
直播主题：
目标用户：
用户最痛的三个问题：
今天要解释的核心规律：
三个公屏关键词：
两个案例：
一个可执行方法：
下一段内容：
收尾总结：
```

然后从本表挑选对应模板，改成符合自身经历、产品和真实能力的表达。不要把五个主播的语言风格直接拼接在一起。
